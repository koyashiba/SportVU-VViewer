## Known limitations

* Automatic calibration is determined only up to the court's symmetry; the user (or a hint) chooses the
  orientation.
* Hosted inference uploads JPEG frames; use it for excerpts, not whole games.
* The number of players per exported moment varies with detections; the reference viewer assumes 10.
* `track_id`s start at 0 and ids are assigned from a track's second sighting (library semantics); the
  first sighting of each track is stored as an untracked box.
